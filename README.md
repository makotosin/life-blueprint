# 人生再点火診断 Ver1.0

GitHub Pagesへそのまま公開できる静的Webアプリです。

## 内容
- 19項目の診断
- 20問目に任意99文字の「羅針盤カード」入力
- 空欄の場合はカードを自動選択
- 5種類の人生タイプ
- 無料レポート
- 印刷・PDF保存
- JSONコピー
- GPT用文章コピー
- JSON保存

## GitHubへ公開
1. ZIPを展開
2. 中の7ファイルをリポジトリ最上位へアップロード
3. Settings → Pages
4. Deploy from a branch
5. main / (root)
6. Save

同名ファイルがある場合は上書きしてください。
