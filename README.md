## PCで確認する方法
`index.html` をダブルクリックしてブラウザで開きます。

## PDF保存
診断終了後に「無料レポートを見る」を押し、
「印刷・PDF保存」からプリンター選択画面を開きます。
保存先として「PDFに保存」を選択してください。

## GitHub Pagesで公開する方法
1. GitHubで `life-restart` リポジトリを作成
2. このフォルダ内のファイルをアップロード
3. Settings → Pages
4. Branchを `main`、フォルダを `/root` に設定
5. Save
6. 公開URLが表示されます
